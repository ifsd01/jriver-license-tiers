## JRiver 的授权是怎么算钱的

JRiver Media Center（常简称 JRMC）是一款本地媒体库软件，音频能处理 FLAC、DSD、APE 这类无损格式，视频支持蓝光和 4K，另外带流媒体和家庭媒体网络功能。它的授权逻辑在软件行业里算老派：

买一次，永久使用。同一大版本内的小版本更新，比如 35.0.1 到 35.0.42，全部免费。跨大版本，比如 35 升 36，要再买一次升级授权。官方的大版本节奏大约一年一个。

这套规则决定了你的实际持有成本。假设你每两年升一次，那升级授权的支出就是两年一次；如果你不追新功能，一份授权用三五年也没人拦你。软件不会到期停用。

官方全新授权和升级授权的价差很大。官网购买页上，全新 Master 授权标价 124.98 美元。官方论坛在 MC30 那一轮公布过升级价：Master 33.98 美元，Windows 和 Mac 各 23.98 美元。这是前几轮的数字，官方后来调过定价，只能当量级参考，别当现价用。

**只有 Windows 设备的人，买 Win 版。** 3 台额度对绝大多数家庭够用，多花的钱换不到你需要的东西。

**全 Mac 环境，买 Mac 版。** 逻辑一样。注意 JRiver 的 Mac 版本这些年一直有兼容性和性能方面的讨论，官方论坛里关于 Apple Silicon 原生支持的争论从 MC27 时期就开始了，一直没有明确的官方时间表。买之前先跑 30 天试用，在你的机器上确认流畅度。

## 常见问题

**已经有旧版授权，还需要再买吗？**
同一大版本内不用，小版本更新免费。跨大版本才需要买升级授权。

**买 Win 版以后换 Mac 怎么办？**
Win 版只覆盖 Windows 设备。换系统要重新买对应平台的授权，或者一开始就上 Master。

**升级授权和全新授权功能上有区别吗？**
没有。升级后拿到的是一份完整的新版授权，永久买断，和全新购买在功能上一致，区别在购买资格和价格。

**一份授权能装几台电脑？**
Win 版和 Mac 版各 3 台同平台设备，Master 版 10 台，可以跨平台混用。

**可以先试用吗？**
可以，30 天全功能试用，不需要注册。
